# PatternFly Glass Mode Standards

Apply these standards whenever `.pf-v6-theme-glass` is active or the user requests Glass Mode, Project Felt with glass, or a glass-enabled PatternFly prototype.

Before generating or editing code, load [PF Glass Check](../skills/pf-glass-check/SKILL.md) and read its required [handbook](../skills/pf-glass-check/references/glass-handbook.md). Follow that skill's implementation workflow and delivery guidance without waiting for an audit request. The handbook owns the component rules, decision table, examples, and audit scope; use those instead of maintaining a separate checklist here.
