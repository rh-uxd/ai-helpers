# Edit notification label

Add a way to rename a notification label from the notification settings page.
The edit changes one short text value, is reversible, and has no destructive
effect. Keeping the user in the settings context is useful.

Repository evidence shows three comparable settings edits in this same product:

1. Rename an escalation policy opens a modal.
2. Rename a notification group opens a modal.
3. Rename a delivery channel opens a modal.

All three are low-risk, one-field edits launched from their settings tables.
There is no evidence from another product and no approved site standard.
