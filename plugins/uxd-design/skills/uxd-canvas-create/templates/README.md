# Canvas templates

If the user names one of these, read that folder's `context.md` and start from its `canvas.json`.

| Request | Folder |
|---|---|
| Vision journey map with paired as-is and to-be frames | `vision-journey-map` |
| Journey map, customer journey, or experience map | `journey-map` |
| Service blueprint | `service-blueprint` |
| User flow or task flow | `user-flow` |
| Affinity map | `affinity-map` |
| Mind map | `mind-map` |

A flowchart, sequence diagram, ERD, or class diagram stays Mermaid. Freeform canvases have no template.
