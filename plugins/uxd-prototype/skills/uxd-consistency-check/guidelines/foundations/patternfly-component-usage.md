## Rule

When PatternFly is selected, review native interactive controls that lack
PatternFly component classes or wrappers. A source match is a review candidate,
not proof of an invalid rendered component: custom wrappers and composition may
be legitimate. Check component documentation before suggesting a replacement.

This rule does not prohibit custom CSS or require a particular product theme.
